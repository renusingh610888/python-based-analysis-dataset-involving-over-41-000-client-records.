## 📌 Project Description

This project analyzes a **bank marketing dataset with more than 41,000 customer records** to predict whether a customer will subscribe to a term deposit. The analysis includes **data preprocessing, exploratory data analysis, and machine learning model building**.

---

## 🎯 Business Problem

Banks need to identify potential customers who are more likely to subscribe to term deposits. This project helps in:
- Understanding customer behavior
- Identifying important factors affecting subscription
- Building prediction models
- Supporting data-driven marketing decisions
